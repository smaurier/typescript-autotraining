# Lab 02 — Fonctions

## Objectifs

- Typer correctement les signatures de fonctions (parametres et retour)
- Utiliser des parametres optionnels et des valeurs par defaut
- Maitriser les parametres rest (rest parameters)
- Implementer des surcharges de fonctions (overloads)
- Typer des callbacks et fonctions d'ordre superieur
- Creer des type predicates (fonctions de garde de type)

## Exercices

Le fichier `exercise.ts` contient 7 exercices progressifs :

1. **Signatures de base** — Annoter des fonctions simples avec leurs types de parametres et de retour.
2. **Parametres optionnels et par defaut** — Utiliser `?` et les valeurs par defaut.
3. **Parametres rest** — Typer des fonctions avec un nombre variable d'arguments.
4. **Surcharges (overloads)** — Definir plusieurs signatures pour une meme fonction.
5. **Callbacks** — Typer des fonctions qui acceptent d'autres fonctions en parametre.
6. **Fonctions d'ordre superieur** — Creer des fonctions qui retournent des fonctions.
7. **Type predicates** — Creer des fonctions de garde de type avec `is`.

## Instructions

1. Ouvrez `exercise.ts`
2. Recherchez les commentaires `// TODO` et completez le code demande
3. Executez le fichier pour verifier vos reponses : `npx tsx exercise.ts`
4. Comparez avec `solution.ts` si besoin
