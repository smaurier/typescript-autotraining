# Lab 03 — Objets et Interfaces

## Objectifs

- Modeliser des entites metier avec des interfaces (`User`, `Product`, `Order`)
- Etendre des interfaces avec `extends`
- Utiliser les propriétés en lecture seule (`readonly`)
- Comprendre le typage structurel de TypeScript
- Manipuler les index signatures
- Combiner des interfaces avec des types d'intersection

## Exercices

Le fichier `exercise.ts` contient 7 exercices progressifs :

1. **Interfaces de base** — Définir des interfaces pour `User` et `Product`.
2. **Proprietes optionnelles** — Ajouter des champs optionnels a vos interfaces.
3. **Readonly** — Proteger certaines propriétés contre la modification.
4. **Extension d'interfaces** — Créer des hierarchies avec `extends`.
5. **Index signatures** — Créer des objets avec des clés dynamiques.
6. **Typage structurel** — Comprendre la compatibilite structurelle.
7. **Modelisation d'une commande** — Combiner toutes les notions dans un modèle `Order`.

## Instructions

1. Ouvrez `exercise.ts`
2. Recherchez les commentaires `// TODO` et completez le code demandé
3. Executez le fichier pour vérifier vos réponses : `npx tsx exercise.ts`
4. Comparez avec `solution.ts` si besoin
