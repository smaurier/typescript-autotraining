# Lab 05 — Classes

## Objectifs

- Créer une hiérarchie de classes avec l'héritage
- Utiliser des classes abstraites et des méthodes abstraites
- Implementer des interfaces avec `implements`
- Maîtriser les parameter properties (raccourci constructeur)
- Utiliser les membres statiques, les getters et les setters
- Comprendre les modificateurs d'acces (`public`, `private`, `protected`)

## Exercices

Le fichier `exercise.ts` contient 6 exercices progressifs :

1. **Classe de base** — Créer une classe `Animal` avec des propriétés et méthodes.
2. **Héritage** — Créer `Chien` et `Chat` qui heritent de `Animal`.
3. **Classes abstraites** — Transformer `Animal` en classe abstraite avec des méthodes abstraites.
4. **Implements** — Créer une interface `Bruyant` et l'implementer.
5. **Membres statiques et parameter properties** — Compteur d'instances, factory pattern.
6. **Getters / Setters** — Encapsuler la logique de validation dans des accesseurs.

## Instructions

1. Ouvrez `exercise.ts`
2. Recherchez les commentaires `// TODO` et completez le code demandé
3. Executez le fichier pour vérifier vos réponses : `npx tsx exercise.ts`
4. Comparez avec `solution.ts` si besoin
