# Lab 05 — Classes

## Objectifs

- Creer une hierarchie de classes avec l'heritage
- Utiliser des classes abstraites et des methodes abstraites
- Implementer des interfaces avec `implements`
- Maitriser les parameter properties (raccourci constructeur)
- Utiliser les membres statiques, les getters et les setters
- Comprendre les modificateurs d'acces (`public`, `private`, `protected`)

## Exercices

Le fichier `exercise.ts` contient 6 exercices progressifs :

1. **Classe de base** — Creer une classe `Animal` avec des proprietes et methodes.
2. **Heritage** — Creer `Chien` et `Chat` qui heritent de `Animal`.
3. **Classes abstraites** — Transformer `Animal` en classe abstraite avec des methodes abstraites.
4. **Implements** — Creer une interface `Bruyant` et l'implementer.
5. **Membres statiques et parameter properties** — Compteur d'instances, factory pattern.
6. **Getters / Setters** — Encapsuler la logique de validation dans des accesseurs.

## Instructions

1. Ouvrez `exercise.ts`
2. Recherchez les commentaires `// TODO` et completez le code demande
3. Executez le fichier pour verifier vos reponses : `npx tsx exercise.ts`
4. Comparez avec `solution.ts` si besoin
