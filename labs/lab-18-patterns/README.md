# Lab 18 -- Patterns TypeScript avances

## Objectifs

- Implementer le pattern `Result<T, E>` (monade de resultat)
- Creer une fonction `pipe()` type-safe
- Implementer un EventEmitter generique type-safe
- Comprendre les patterns fonctionnels en TypeScript

## Exercices

1. **`Result<T, E>`** -- Ok/Err avec chainage (map, flatMap, unwrap)
2. **pipe()** -- Composition de fonctions type-safe
3. **EventEmitter type-safe** -- Emetteur d'evenements generique

## Lancer les tests

```bash
npx ts-node lab-18-patterns/exercise.ts
npx ts-node lab-18-patterns/solution.ts
```
