# Lab 19 -- Projet final

## Objectifs

- Combiner toutes les notions vues dans les labs precedents
- Implementer une mini-bibliotheque utilitaire complete
- Pratiquer les patterns avances TypeScript dans un contexte realiste
- Creer une API coherente et type-safe

## Composants a implementer

1. **`Result<T, E>`** -- Monade de resultat avec chainage complet
2. **TypedEventEmitter** -- Emetteur d'evenements generique type-safe
3. **pipe()** -- Composition de fonctions type-safe
4. **Schema Validation** -- Validation de schemas simple et type-safe
5. **Integration** -- Combinaison de tous les composants
