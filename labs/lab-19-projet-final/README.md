# Lab 19 -- Projet final

## Objectifs

- Combiner toutes les notions vues dans les labs précédents
- Implementer une mini-bibliotheque utilitaire complete
- Pratiquer les patterns avances TypeScript dans un contexte realiste
- Créer une API coherente et type-safe

## Composants a implementer

1. **`Result<T, E>`** -- Monade de résultat avec chainage complet
2. **TypedEventEmitter** -- Emetteur d'événements générique type-safe
3. **pipe()** -- Composition de fonctions type-safe
4. **Schema Validation** -- Validation de schemas simple et type-safe
5. **Intégration** -- Combinaison de tous les composants
